# Documentation

This directory contains all the documentation, logs, and diagrams related to the TinyML ESP32 Early Exit Inference project.

## Files
- \diagrams.md\: Architecture and flowchart descriptions.
- \
otes.md\: General development notes, observations, and to-do items.
- \power_results.csv\: Logs of power consumption measured on the ESP32.
- \	raining_log.csv\: Logs detailing model training metrics (accuracy, loss).
